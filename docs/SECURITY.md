# 安全边界

这个项目是**单用户、仅本机**的运维看板，不是面向多用户或公网的服务。请按这个前提部署。

## 网络

- 服务只绑定 `127.0.0.1`，不要改成 `0.0.0.0`，也不要做端口转发；
- 没有 TLS。把明文 HTTP 暴露到局域网或公网会让会话 Cookie 与密码处于风险中；
- 反向代理、多用户、远程访问都不在本项目的支持范围内。

## 认证与会话

- 单一本地用户 `admin`，密码只保存为 PBKDF2-SHA256（600,000 次迭代）哈希；
- 配置文件 `admin.json`、会话密钥 `session.key` 位于数据目录，权限 `0600`，目录 `0700`；
- 会话是 HMAC-SHA256 签名的 HttpOnly Cookie（`SameSite=Strict`，12 小时）；
- 所有非 GET 接口要求与会话绑定的 `X-CSRF-Token`，并校验 `Origin` 与 `Host` 一致；
- 登录失败有每 IP 限流；审计日志不记录密码、Cookie 或密钥。

## 技能数据

- 被扫描的 Skill 内容一律视为**不可信数据**：只做静态读取与哈希计算，绝不执行其中任何脚本；
- 不读取 `~/.hermes/.env`、SSH 私钥、浏览器凭据等密钥文件；报告中禁止出现密钥原文；
- 未经用户逐项批准，不修改、删除、合并、重命名、移动、安装或卸载任何技能，也不修改 Hermes 全局配置；
- 执行变更前先完整备份；回滚只覆盖提案登记的目标文件，受保护文件只做哈希核对与告警。

## 本仓库的公开边界

公开仓库只包含程序、通用规则与虚构示例，明确不包含：

- 真实技能清单、绝对路径与逐文件哈希（`registry/`）；
- 真实审计报告、周报月报与个人决策（`reports/`、`audits/`）；
- 真实提案与变更记录（`proposals/pending|approved|rejected/`）；
- 操作日志与备份（`logs/`、`backups/`）；
- 登录配置、会话密钥、产生方式覆盖与常用列表（`dashboard/config/`、`dashboard/data/`）；
- 任何 `.env`、token、webhook 或投递凭据。

发布前会做敏感词扫描（`token`、`secret`、`password`、`webhook`、`api_key`、绝对个人路径等），并启用 GitHub secret scanning。如果你发现遗漏，请开 issue 描述位置，不要贴出真实凭据。

## 漏洞反馈

请通过 issue 反馈，附最小复现步骤；不要在 issue 中粘贴密码、Cookie、密钥或真实技能内容。
